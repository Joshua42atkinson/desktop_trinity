# 🗑️ Dumpster Universe

> **"Great ideas that aren't ready for prime time."**

This is the **idea dump** for Trinity. When you have a brilliant idea that would distract from the current goal, put it here instead of implementing it.

## Purpose

1. **Capture scope creep** - Ideas that are great but not NOW
2. **Archive research** - External references of what's out there
3. **Preserve possibilities** - Seeds for future versions

## Folders

| Folder | Purpose |
|--------|---------|
| `ideas/` | New feature concepts, plugins, integrations |
| `scope_creep/` | Features that got too big mid-development |
| `research/` | External projects, papers, inspiration |

## Rules

1. **Write it down, then move on** - Don't implement, just capture
2. **One idea per file** - Makes it easy to promote later
3. **Include the "Why"** - What problem does this solve?
